# V122 · Protección de datos OneDrive
- Un dispositivo vacío nunca sobrescribe una copia remota válida.
- Si el dispositivo está vacío y existe una copia válida, se restaura OneDrive.
- Antes de sustituir mi-servicio.json se guarda mi-servicio-anterior.json.
- La restauración recupera también agendaSalidas.
- No se modifican las claves de registros/preferencias ni la interfaz visual de V121.
